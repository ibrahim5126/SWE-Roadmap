# Day 1 — Learning Log

1. `print("Hello world")` — used for output.

2. `input("")` — used for taking input in a program.

   Example:
   ```python
   name = input("Name: ")
   print(name)
   ```

3. Variables:
   ```python
   name = input("Name: ")
   print(name)
   ```

4. Comments — `#` for single-line comments.

5. F-strings:
   ```python
   name = input("Enter your name: ")
   print(f"Hello, {name}")
   ```

6. `variable_name.strip()` — removes whitespace from the beginning and end of a string.
